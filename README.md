### 🛠️ How I build projects

Every flagship repository aims to include:

1. A **working application** with a clear local setup.
2. An **explainable modeling approach**, including limitations and evaluation.
3. **API contracts**, tests, and meaningful error handling.
4. **Architecture notes**, reproducible dependencies, and deployment instructions.
5. **Screenshots or a live demo** once one is available.

> Focus: strong engineering + transparent ML, not just notebooks or AI buzzwords.
